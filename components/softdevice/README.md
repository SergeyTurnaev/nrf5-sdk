# SoftDevice для nRF52

| Каталог | Версия | FWID |
|---|---|---|
| s112 | 7.3.0 | 0x126 |
| s113 | 7.3.0 | 0x125 |
| s122 | 8.1.1 | 0x112 |
| s132 | 7.3.0 | 0x124 |
| s140 | 7.3.0 | 0x123 |

Содержимое дистрибутивов Nordic размещено в структуре SDK:

- `headers/` — файлы из `<SoftDevice>_API/include/`, включая `nrf52/`.
- `doc/ble_api.dox` — исходник справки из `<SoftDevice>_API/doc/` для Doxygen.
- `doc/<SoftDevice>_release-notes.pdf` — актуальные примечания к выпуску.
- `doc/<SoftDevice>_license-agreement.txt` — лицензия текущего выпуска.
- `hex/` — исходный HEX и его лицензия, как в штатной структуре SDK.

Отдельных `migration-document.pdf` в новых комплектах нет. Документы старых
версий удалены; они доступны в истории Git. Новые HEX и PDF скопированы
побайтово, текстовые файлы приведены к LF.

`headers/nrf_sd_def.h` и имеющиеся `toolchain/` относятся к интеграции SDK:
их нет в отдельных комплектах SoftDevice, поэтому они сохранены.
Пути к HEX в примерах SDK обновлены на перечисленные версии.

Каталоги `common`, `mbr`, `s212`, `s312`, `s332`, `s340` относятся к другим
компонентам и не входят в эту замену.
